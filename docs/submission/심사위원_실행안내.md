# 심사위원 실행 안내 (2,000자 이내 원고)

---

로그인 없이 https://oneroof-17dq.axhub.app 에서 바로 쓸 수 있습니다. 화면 오른쪽 위 버튼으로 역할(영업지원팀·영업임원·회계·자금팀)을 바꿉니다. 테스트 계정은 없습니다. 권한은 서버가 검사해서, 권한 없는 역할로 결정하면 거부됩니다. 모든 값에는 출처 배지(원본·부서 주장·가정·모의 회신·계산 결과·AI 생성)가 붙습니다. 데이터는 과제 원본이고 기준일은 2026-07-01입니다.

추천 순서(약 10분)
1. 관련자 메뉴: D-011·D-024·D-037 그룹의 일치 근거(대표자·주소·계좌, 실제 입금 계좌)와 월별 합산을 봅니다.
2. 영업지원팀 → 처리할 일 → "정산 접수": 6월 40건 중 37건이 전결 대기로, 그룹 1건(합산 3,888,097원)이 영업임원으로 갑니다.
3. "한도 이내 37건 일괄 승인": 19건은 은행으로 가고, 90일 넘게 연체된 18곳은 회계·자금 상계 검토로 갑니다. 지급 메뉴에서 "이체 완료 회신"(모의 은행)을 누르면 지급 완료로 바뀝니다.
4. 영업임원 → RPG-D-011 반려: 확정이 아니라 관계 소명 요청이 나갑니다.
5. 영업지원팀 → 변경·예외 → 요청 카드에 회신을 입력하고 "소명 제출"(모의 대리점 회신)을 누릅니다. 몇 초 뒤 AI 회신 해석(미답변·확인할 일)이 나타납니다.
6. 영업임원 → "소명 첨부 재상신" 건 → 체크리스트를 확인하고 승인합니다. 체크한 항목은 결정 사유와 감사 로그에 남습니다.
7. 회계·자금팀 → 채권·상계: 확장 켬·끔 비교를 봅니다(상계 21곳 20,806,770원). 처리할 일에서 상계 결정 화면을 보고 "상계 제안 일괄 결정"을 누르면 미수금이 줄고 상계 통지가 나갑니다.
8. 변경·예외 → 상계 통지 카드에서 "이의 제기" → 회계·자금팀 재검토 → "이의 인정 · 상계 취소"를 누르면 전액 지급되고 미수금이 되살아납니다.
9. 조건 변경: 변경·예외 → "시연 예시 채우기" → 정정 신고를 하면 새 그룹과 지난달 사후 확인이 생깁니다. 채권·상계 → 대리점 행 "입금"을 누르면 결정 전 상계 제안이 다시 계산됩니다.
10. 감사 로그: 모든 결정·회신·상태 변경을 검색할 수 있습니다.

유의 사항
- 은행 회신과 대리점 회신은 모의 입력이고, 그 뒤의 상태 변경은 시스템이 직접 합니다.
- 공개 서버는 초기화를 꺼 두었습니다. 다른 분이 먼저 처리했다면 그 상태에서 이어집니다(예: 6월이 이미 접수됨). 처음 상태로 보고 싶으시면 시연 영상과 저장소의 로컬 실행 방법(`app/README.md`)을 참고해 주세요.
- AI 해석은 무료 Gemini를 씁니다. 혼잡하면 수십 초 걸리거나 규칙 기반 해석으로 대체되며, 화면에 그 사실이 표시됩니다.
- API 문서는 /swagger-ui.html 입니다.
